# 옵티마이저 · 적응형 학습 안내 (v0.2.0)

## 옵티마이저 고르기

처음이라면 **AdamW 8bit** (기본값) 그대로 쓰세요. 아래 표는 목적별 추천입니다.

| 상황 | 추천 | 학습률 |
|---|---|---|
| 무난하게, 12GB 이하 | AdamW 8bit | 1e-4 |
| 자꾸 OOM 이 난다 | Paged AdamW 8bit / Paged AdEMAMix 8bit | 1e-4 |
| 3000 스텝 이상 긴 학습 | AdEMAMix 8bit | 1e-4 |
| 학습률 고민하기 싫다 | Prodigy + Schedule-Free / Prodigy | 1.0 |
| 학습률을 자동으로, 추가 설치 없이 | Automagic3 (Ostris v3, Fizgig 과 동일) | 1e-6 (시작값) |
| 원소별 학습률 조정 (초기 방식) | Automagic (v1 방식) | 1e-4 (시작값) |
| 메모리를 최대한 아끼고 싶다 | Adafactor / CAME / Lion 8bit | 1e-4 / 1e-4 / 3e-5 |
| 총 스텝을 정하기 어렵다 | AdamW Schedule-Free | 2e-4 |

- 옵티마이저를 바꾸면 학습률이 범위에 맞지 않을 때 자동으로 권장값으로 바뀝니다 (예: AdamW → Prodigy 면 1e-4 → 1.0).
- **권장값 적용** 버튼은 학습률 · weight decay · 스케줄을 한 번에 권장값으로 채웁니다.
- 목록에 `(설치 필요)` 가 보이면 `install.bat` 을 다시 실행하세요.
- Automagic3 는 학습률을 스스로 관리하므로 스케줄러 · 적응형 '정체 감지' 가 꺼집니다. 발산 복구와 실시간 학습률 배율은 내부 학습률에 직접 반영됩니다.
- Lion 계열은 AdamW 보다 학습률을 3~10배 낮게, weight decay 는 크게 잡아야 합니다.
- Schedule-Free 계열은 스케줄러가 자동으로 '일정' 이 되며, 저장 · 샘플 시 평균 가중치를 사용합니다.
- bitsandbytes 를 쓸 수 없는 환경이면 8bit 옵티마이저는 AdamW (Lion 8bit 는 내장 Lion) 로 자동 대체되고 로그에 표시됩니다.

## 적응형 학습

학습 설정 → **적응형 학습 (실시간 자동 조정)** 카드에서 켭니다. 기본값은 꺼짐입니다.

| 기능 | 하는 일 |
|---|---|
| 정체 감지 | 정해진 스텝 동안 loss 가 1% 이상 좋아지지 않으면 학습률 배율을 낮춤 (하한까지) |
| 발산 복구 | loss 급등이 5스텝 이상 이어지거나 NaN 이 나오면, 100스텝마다 저장해 둔 직전 정상 지점(LoRA + 옵티마이저 상태)으로 되돌리고 학습률을 절반으로 |
| 자동 클리핑 | 최근 200 스텝 그래디언트 크기의 중앙값 × k 로 클리핑 |
| 검증 평가 | 고정 노이즈 · 고정 타임스텝(0.25/0.5/0.75)으로 loss 를 측정. 학습 loss 보다 흔들림이 훨씬 적어 추세 판단에 좋음 |
| 검증 전용 이미지 | 지정한 수만큼 이미지를 학습에서 빼서 평가에만 사용 → 과적합 판단 가능 |
| 조기 종료 | 검증 loss 가 연속으로 개선되지 않으면 학습을 끝내고 **가장 좋았던 시점의 가중치**로 최종 LoRA 저장 |

모든 자동 조정은 실행 페이지 그래프에 **주황 점선**으로, 검증 loss 는 **초록 선**으로 표시되고 로그에 이유가 남습니다.
학습률 칸에는 실제 학습률(Prodigy 는 추정값, Automagic 은 평균값)과 현재 배율이 함께 표시됩니다.

### 실시간 학습률 배율

실행 · 모니터 페이지의 **학습률 배율** 에 값을 넣고 **적용** 을 누르면 다음 스텝부터 반영됩니다.
적응형 학습을 꺼도 사용할 수 있습니다. loss 가 튀면 ×0.5, 학습이 너무 느리면 ×1.5 처럼 조절하세요.

### 권장 조합

- 처음 써보기: 적응형 켜기 + 기본값 (정체 감지 · 발산 복구 · 검증 100스텝마다 4장)
- 과적합이 걱정될 때: 검증 전용 이미지 1~2장 + 조기 종료 (인내 5회)
- 데이터가 10장 미만: 검증 전용 이미지는 0 으로 두고 조기 종료는 끄세요 (평가가 학습 이미지 기준이라 과적합을 판단하지 못함)

### 설정 파일

`train.adaptive` 섹션에 저장됩니다. v0.1 설정 파일은 그대로 열리며 적응형 학습은 꺼진 상태가 됩니다.

## LoRA 점검 도구

`LoRA점검.bat` 에 `.safetensors` 파일을 끌어다 놓으면 아래를 알려줍니다 (인자 없이 실행하면 output 폴더의 최근 5개 검사).

- 학습이 실제로 되었는지: `lora_up` 은 0 에서 시작하므로 평균 |w| 가 0 에 가까우면 학습 자체가 안 된 것
- 발산(NaN) 여부, 블록별 가중치 변화량, 키 형식(kohya / ComfyUI), 학습 당시 설정
- 학습은 됐는데 ComfyUI 에서 효과가 없다면 확인할 항목

v0.2.0 부터는 학습 중 저장할 때마다 로그에 `LoRA 변화량` 이 함께 표시됩니다.
